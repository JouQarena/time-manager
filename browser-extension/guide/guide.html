Time Manager Companion

This extension is the half of Time Manager that makes website rules work: the desktop app counts apps and games by itself, but only the browser knows which site you are actually looking at.

Checking the link…

What it does

  • Reports the active tab's domain — and only while the browser window is focused, so background tabs and minimised windows never count against you.
  • Shows the block page locally in the tab when a website limit is reached, with the reason and the reset time.
  • Keeps the agent honest in the UI: a toolbar badge (!) tells you when the link to the desktop app is down, so you are never misled into thinking a limit is being enforced when it is not.

What it never does

  • It never sends URLs, page titles, search terms or page content — only the domain (for example youtube.com).
  • It talks only to 127.0.0.1 on this computer. There is no server, no account, no telemetry.
  • It cannot block anything by itself: the desktop agent decides, the extension renders. If the agent is not running, nothing is counted and nothing is blocked.
  • Timestamps from the browser are never used for accounting — the agent stamps everything with its own clock.

Install & pair in three steps

  1. Start the desktop app. Run TimeManagerTray.exe and leave it running — the extension needs a live agent.
  2. Copy the pairing token. In the app open Settings ▸ Browser extension and press Copy (or run TimeManager.exe --show-token). The token is a machine secret, like a password.
  3. Paste it here. → paste into Agent token → Save & test. The badge stops showing “!” once the link is up.

Full walkthrough with fixes for every error: docs/INSTALL-EXTENSION.md in the app folder.

The badge, decoded

BadgeMeaning
! The extension is not connected to the desktop app. Website limits are not being enforced and website time is not being counted. Open settings and check the token and port.
(nothing) Connected and this tab is fine. Time is counting only if the tab is active and the window is focused.
⛔ The site in the current tab is blocked by a rule you created.

When time stops counting

  • The tab is in the background, the window is minimised, or another application has focus — none of these count.
  • Chrome may suspend the extension's worker after idling or sleeping. Time Manager then stops counting website time (it never invents usage) and reconnects on your next tab change, browser restart or within a minute via its own alarm.
  • Closing the browser, quitting the desktop app or switching to a browser profile that was never paired: the link simply goes down and the badge shows “!”.

Troubleshooting

SymptomWhat to do
Badge always shows “!”, settings say not reachable — is the agent running? Start TimeManagerTray.exe. If it is already running, compare Agent port here with Settings ▸ Browser extension ▸ Agent port in the app — they must match (default 17846).
Settings say AUTH_FAILED The token is wrong or was regenerated. Copy it again from the app and re-paste it. Regenerating disconnects every browser on purpose.
Agent did not reply to HELLO Something answered on that port but was not Time Manager — most often a port clash. Change the agent port in the app, then use the same number here.
Connected, but the desktop dashboard still says No browser connected Each browser profile is paired separately. Repeat the three steps in every browser and profile you use (Chrome and Edge, and each Windows user).
A blocked site is still reachable after you paused or disabled the rule Reload the tab: the block page is removed as soon as the agent sends the updated decision, and an open page does not always notice instantly.
Nothing is blocked at all, no “!” The agent is connected but no Website rule matched this domain. Check the rule in the app: domain only (youtube.com, not the full URL), the rule enabled, and its schedule active now.

Updating & uninstalling

  • Update: after updating the desktop app, open chrome://extensions and press Reload on the Time Manager card. Your token stays valid — no re-pairing.
  • Uninstall: chrome://extensions → Remove. Website rules stay in the app's database; they simply stop being enforced without the extension.

Local-only by design: no cloud, no accounts, no telemetry. Everything this extension knows lives in this browser profile and on this machine.
