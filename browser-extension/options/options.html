Time Manager Companion

This extension talks only to the Time Manager agent running on this computer (127.0.0.1). Nothing is sent anywhere else.

Pairing

  1. In the desktop app run python -m app.main --show-token.
  2. Paste the 64-character token below.
  3. Press Save & test — the badge should stop showing “!”.

Privacy & limitations

  • Only the domain of the active tab is reported — never URLs, page titles or content.
  • Timestamps from this extension are never used for accounting; the agent stamps everything with its own clock.
  • Blocks are rendered locally in the page; no traffic is proxied.
  • If the agent is not running, nothing is counted (the UI shows “Agent not reachable”).
  • Chrome may suspend the service worker while the browser idles; the agent then pauses website timers until the link returns.
